          Add a new model
          
          administrator only
        
              

        
              
          Only an administrator can add a model to this computer. Change
          You are in the top bar to an administrator if that is
          your job here. Attempts are recorded either way.
        
              

        
              
          
          
              
            
              
              
              1. Put the file on this computer
              
              
              
                Drop a .gguf file here
                or click to choose one
                
              
              
              
              
                Model files are gigabytes. Copying one into the models folder
                in File Explorer and pressing Scan the folder is faster
                and far less fragile than sending it through this page.
              
              
              
              
                
                -
              
              
              
              
            
              

            
              
              
              2. What happens next
              
              
                
                
              1. The file's header is read here on this computer - no
                    network - to get its architecture, context length and size.
                2. 
                
              2. Its SHA-256 is recorded, so the box can tell later if the
                    file was swapped.
                3. 
                
              3. It is written into config/models.yaml
                    and into this profile's available list. Both are
                    needed: a model in only the first is never chosen, with no
                    error anywhere.
                4. 
                
              4. The registry reloads. The model is a routing candidate on
                    the next request - no restart, no code change.
                5. 
              
              
              
              
                Its memory use and speed are estimated from the file, and
                its quality scores are seeds, not measurements. Run the
                evaluation harness before trusting how the router ranks it.
              
              
            
              
          
              

          
              

          
              Where to get a model
              
          
                
            
              1. On a computer that does have internet, open
                huggingface.co and search for the
                model you want with GGUF in the name -
                for example Qwen2.5-7B-Instruct-GGUF.
                GGUF is the only format this box loads.
                2. 
            
              2. Download one .gguf file, not the whole
                repository. Q4_K_M is the usual choice:
                roughly half the size of the original with little quality lost.
                As a rule of thumb the file must be about 1 GB smaller than
                your graphics memory.
                3. 
            
              3. For a model that reads images, also download its
                mmproj-*.gguf projector file. Without
                it the model loads, answers, and never looks at the picture -
                so this box refuses images until the projector is present.
                4. 
            
              4. Copy the file onto a USB stick, then into the models folder
                shown above on this computer.
                5. 
            
              5. Press Scan the folder, check what it found, and press
                Add it.
                6. 
          
              
          
              
            Nothing in this process reaches the internet from this computer. The
            download happens on a different machine, and the file arrives by
            hand - which is the whole point of an air-gapped box.
